# AdaLigand 六类配体规模、重原子与 ligand-area-mask 重叠统计

> 统计日期：2026-08-09 至 2026-08-10  
> 数据根目录：`/storage/penghongen/AdaLigand/Ori_Data`  
> PDB 母集合：`raw/pair_list.jsonl` 中的 22,386 个 PDB  
> 当前数据划分：`stage1_preparation_box_pool_2/split/`  
> 任务性质：只读统计。服务器正式数据、代码、清单、数据划分和 BOX pool 均未修改。

## 1. 结论先行

1. 六类在“occurrence 数量”“present 重原子数量”和“ligand-area 体素数量”三个统计单位下非常不同，不能共用一套直觉或未经说明的类别权重。
   - `ion` 占全部 occurrence 的 50.38%，但只占 present 重原子总数的 2.96%。
   - `small_molecule` 占 occurrence 的 32.33%，却占 present 重原子总数的 73.14%。
   - 单个 `ion` occurrence 的 present 重原子数中位数为 1，但单原子的范德华球 mask 中位数为 44 个体素；除离子外的类别通常约为每个 present 重原子 10 至 12 个 mask 体素。
2. 沿 PDB 轴存在很长的负载尾部。
   - 每个 PDB 的 `small_molecule` occurrence 数中位数为 1、99% 分位数为 177.15、最大为 4,482。
   - 每个 PDB 的 `small_molecule` present 重原子总数中位数为 35、99% 分位数为 7,798.95、最大为 202,140。
   - 每个 PDB 的 `ion` occurrence 数中位数为 1、99% 分位数为 359.3、最大为 1,909。
3. 类别内部的“平均重原子数”必须说明怎样给 PDB 加权。
   - 按 occurrence 等权时，`small_molecule` 平均为 38.49 个 present 重原子。
   - 先在每个含 `small_molecule` 的 PDB 内求平均，再让每个 PDB 等权时，平均为 29.29。
   - 两者差异说明大 occurrence 或 occurrence 多的 PDB 会显著改变全局均值。
4. `other` 极少：166 / 678,001 = 0.0245% occurrence；仅出现在 97 / 22,386 = 0.433% PDB。当前训练划分中有 80 个，验证集有 2 个，校准集为 0，留出测试池有 55 个。这个数量支持把它作为审计类别单独报告，不支持为它引入复杂的监督逻辑。
5. 任意两个同 PDB occurrence 的 mask 重叠在总体上很少，但存在高度集中的完全重复簇。
   - 22,309 个 mask 完整 PDB 内共有 98,150,615 个无序 occurrence 对；57,474 对有至少一个共享体素，比例为 0.05856%。
   - 6,514 个正重叠对的两个 mask 完全相同，占全部正重叠对的 11.33%。这些完全重复对全部属于同一类别、同一 `object_key`；没有跨类别完全重复 mask。
   - `8e33` 中 103 个 `CCD:UDU` occurrence 具有同一个 1,116-体素 mask，单独产生 5,253 个完全重复对；`8dwh` 中 31 个 `CCD:U2U` occurrence 产生另 465 个完全重复对。
6. 跨类别冲突仍然很小，且主要来自 `small_molecule` 与 `ion`。
   - 全部 140,182,477 个按 PDB 分别计数的 ligand-area 并集体素中，241,669 个被至少两个不同类别覆盖，占 0.17240%。
   - 23,446 个跨类别正重叠 occurrence 对中，22,125 个是 `small_molecule–ion`，占 94.37%。
   - 跨类别没有完全相同 mask。因此，如果未来用简单类别先后顺序消解 softmax 标签冲突，统计上不需要复杂的实例级冲突算法；但必须把固定顺序写入标签契约，以保证结果可复现。
7. `occurrences.jsonl::n_heavy_atoms` 不能不经核对地当作唯一重原子真值。`ligand_coords.npz::present_{candidate_id}.sum()` 与它在 676,951 / 678,001 = 99.845% occurrence 上相等；1,050 个不相等项中，记录值始终不大于 present 数，最大差为 102。本文以实际参与 mask 构造的 present 原子数作为主要重原子口径。

## 3. 严格形式化定义

### 3.1 PDB、occurrence 和类别

令：

- `P_occ` 为 occurrence 可读 PDB 集合；
- `O_p` 为 PDB `p` 中的 occurrence 集合；
- `C` 为上述六类集合；
- `tau(o)` 为 occurrence `o` 的 `type_tag`；
- `kappa(o)` 为 occurrence `o` 的 `object_key`；
- `1[条件]` 为示性函数：条件成立取 1，否则取 0。

PDB `p` 中类别 `c` 的 occurrence 数定义为：

```text
N[p,c] = sum over o in O_p of 1[tau(o) = c]
```

含类别 `c` 的 PDB 集合与 PDB 覆盖率定义为：

```text
P_c = {p in P_occ : N[p,c] > 0}
prevalence[c] = |P_c| / |P_occ|
```

类别 occurrence 比例定义为：

```text
occurrence_fraction[c]
  = sum_p N[p,c] / sum_p |O_p|
```

### 3.2 四种原子数口径

对 occurrence `o` 定义：

- `h_record(o)`：`occurrences.jsonl::n_heavy_atoms`；
- `h_slot(o)`：`ligand_coords.npz::present_{candidate_id}` 的数组长度；
- `h_present(o)`：`present_{candidate_id}` 中 `True` 的数量；
- `h_template(o)`：`ligand_objects/{safe_object_key}.npz::atoms` 的长度。

形式化写作：

```text
h_present(o) = sum_j 1[present_o[j] = True]
h_slot(o) = length(present_o)
h_template(o) = length(template_atoms[kappa(o)])
```

`h_slot` 与 `h_template` 本次对全部 678,001 个 occurrence 严格相等。`h_present` 只统计沉积结构中实际存在并参与 ligand-area mask 构造的原子，因此本文把它作为主要重原子规模。

### 3.3 沿 PDB 轴的重原子统计

PDB `p` 中类别 `c` 的 present 重原子总数：

```text
H[p,c] = sum over o in O_p of 1[tau(o)=c] * h_present(o)
```

同一 PDB、同一类别内部的 occurrence 平均 present 重原子数：

```text
A[p,c] = H[p,c] / N[p,c], only when N[p,c] > 0
```

本文同时报告两个容易混淆的全局均值：

```text
mu_occ[c]
  = sum_p H[p,c] / sum_p N[p,c]

mu_pdb[c]
  = (1 / |P_c|) * sum over p in P_c of A[p,c]
```

- `mu_occ` 让每个 occurrence 等权；occurrence 多的 PDB 权重更大。
- `mu_pdb` 先在每个 PDB 内求类别平均，再让每个含该类别的 PDB 等权。

类别 `c` 在 PDB `p` 中的唯一化学身份数与 occurrence 重复倍数：

```text
K[p,c] = number of distinct kappa(o), for o with tau(o)=c
R[p,c] = N[p,c] / K[p,c], only when K[p,c] > 0
```

### 3.4 分布汇总算子

对任意有限数值集合 `X={x_1,...,x_n}`，本文的平均数和总体标准差为：

```text
mean(X) = (1/n) * sum_i x_i
std_pop(X) = sqrt((1/n) * sum_i (x_i - mean(X))^2)
```

分位数使用 NumPy 2.2.6 的默认线性插值 `numpy.quantile(..., method="linear")`。通常报告 `p01`、`p05`、`p25`、`p50`、`p75`、`p90`、`p95`、`p99`。

“沿 PDB 轴、全 PDB”表示每个 `p in P_occ` 都贡献一个数，未含该类别的 PDB 贡献 0；“仅正 PDB”表示只在 `P_c` 上统计。两种分布不能混用。

### 3.5 occurrence mask 和类别 mask

对 `p in P_mask` 中的 occurrence `o`，令 `M_o` 为 `mask_{candidate_id}` 中去重后的 ZYX 体素坐标集合，单 occurrence 体素数为：

```text
V(o) = |M_o|
```

PDB `p`、类别 `c` 的 occurrence mask 体素数之和与类别并集体素数为：

```text
V_sum[p,c] = sum over o in O_p, tau(o)=c of |M_o|

M_class[p,c] = union over o in O_p, tau(o)=c of M_o
V_union[p,c] = |M_class[p,c]|
```

同类 occurrence 内部重复覆盖比例为：

```text
W[p,c] = 1 - V_union[p,c] / V_sum[p,c]
```

只在 `V_sum[p,c] > 0` 时定义。本文的 micro 同类重复覆盖比例为：

```text
W_micro[c]
  = 1 - sum_p V_union[p,c] / sum_p V_sum[p,c]
```

单 occurrence 每个 present 原子的 mask 体素数为：

```text
D(o) = V(o) / h_present(o), when h_present(o) > 0
```

### 3.6 任意两个 occurrence 的 mask 重叠

只比较同一个 PDB 内不同 occurrence。对 `p in P_mask`，全部无序 occurrence 对为：

```text
Q_p = {{o_i,o_j} : o_i,o_j in O_p, i < j}
```

`i < j` 保证每一对只统计一次，不统计 occurrence 与自身的配对。

对任意 `{o_i,o_j} in Q_p`，定义：

```text
I[i,j] = |M_i intersect M_j|
U[i,j] = |M_i union M_j| = |M_i| + |M_j| - I[i,j]
IoU[i,j] = I[i,j] / U[i,j]
Dice[i,j] = 2*I[i,j] / (|M_i| + |M_j|)
C_min[i,j] = I[i,j] / min(|M_i|, |M_j|)
```

- `I` 是共享体素数。
- `IoU` 衡量两个 mask 相对于并集的重叠。
- `Dice` 是另一种对称重叠系数。
- `C_min` 表示较小 mask 有多少比例被较大 mask 覆盖，适合识别“一个 mask 几乎被另一个包含”的情况。

正重叠对定义为 `I[i,j] > 0`。完全重复 mask 定义为 `IoU[i,j] = 1`，等价于 `M_i = M_j`。

本文同时报告：

1. 全部 occurrence 对分布：零重叠对的四项指标都记为 0；
2. 条件正重叠分布：只在 `I>0` 的 occurrence 对中计算。

由于正重叠率低于 1%，只报告条件分布而不说明分母会严重夸大重叠程度。

### 3.7 类别对与体素冲突

类别对采用无序定义。若 `c != d`，同一 PDB 中该类别对的总 occurrence 对数为：

```text
T[p,c,d] = N[p,c] * N[p,d]
```

若 `c = d`：

```text
T[p,c,c] = N[p,c] * (N[p,c]-1) / 2
```

类别并集 mask 的 micro IoU 定义为：

```text
J_micro[c,d]
  = sum_p |M_class[p,c] intersect M_class[p,d]|
    / sum_p |M_class[p,c] union M_class[p,d]|
```

对 PDB `p` 的任意 ligand-area 并集体素 `v`，定义 occurrence 覆盖重数和类别覆盖重数：

```text
m_occ[p,v] = sum over o in O_p of 1[v in M_o]

m_class[p,v]
  = number of distinct c for which v in M_class[p,c]
```

- `m_occ >= 2` 表示至少两个 occurrence 覆盖该体素；
- `m_class >= 2` 表示至少两个不同类别覆盖该体素，是 softmax 类别冲突的直接计数。

## 13. 对后续监督设计的直接含义

以下是统计事实支持的设计约束，不是本文替用户作出的发布决定。

### 13.1 类别权重必须点名统计单位

至少存在三种不同分母：

1. occurrence 等权：`ion` 占 50.38%；
2. present 重原子等权：`small_molecule` 占 73.14%，`ion` 仅占 2.96%；
3. ligand-area 体素等权：离子虽只有一个原子，但每个 occurrence 通常产生约 44 个体素。

因此，“按类别频率加权”不是完整规格。配置或论文必须写明频率按 occurrence、PDB、原子还是体素计算。

### 13.2 建议同时报告 micro、PDB macro 和 per-class 指标

- occurrence micro 容易被数量庞大的离子主导；
- 原子或体素 micro 容易被 `small_molecule` 和大 PDB 主导；
- PDB macro 会显著降低 occurrence 多的 PDB 权重；
- per-class 指标能避免稀有的 `peptide_like`、`nucleotide_like` 被总分掩盖。

### 13.3 batch 与损失归一化要处理 PDB 长尾

`small_molecule` occurrence/PDB 最大 4,482，`ion` 最大 1,909；`small_molecule` present 重原子总数/PDB 最大 202,140。若一个 PDB 作为不可拆的逻辑单元，应设置显式的工作量分桶、分块或单独 batch 机制，而不是只按 PDB 数固定 batch。

### 13.4 mask 冲突可以保持简单，但顺序必须确定

- 跨类别冲突体素只占 ligand-area 并集体素的 0.1724%；
- 没有跨类别完全重复 mask；
- 绝大多数跨类别正对是 `small_molecule–ion`。

这些数据支持按固定类别名顺序或固定 class ID 顺序解决冲突，不支持为极少数体素引入复杂实例竞争逻辑。无论选择哪种顺序，都应写入标签文件的 schema/provenance，避免不同运行产生不同标签。

### 13.5 完全重复 occurrence 是否降权是独立问题

完全重复 mask 组全部同类别、同身份，不造成 softmax 类别冲突；但如果 loss 按 occurrence 累加，它们会重复施加相同空间监督。是否保留这种隐式权重、按唯一 mask 降权或只在指标中去重，应由监督目标决定，不能与类别冲突处理混为一件事。

## 14. 限制与未作出的推断

- mask 重叠只在同一 PDB 内计算。不同 PDB 的 ZYX 坐标不在同一物理坐标系中，跨 PDB 比较没有意义。
- 本统计读取逐 occurrence 稀疏 `mask_{candidate_id}`，没有解压或重新验证 dense `union_mask`。因此统计结果直接反映实例 mask，不承担 schema v3 `union_mask` validator 的职责。
- 77 个缺少 `ligand_area.npz` 的 PDB 未进入 mask 分母；没有把缺失 mask 当成空 mask。
- 完全重复 mask 只表示两个离散体素集合相等，不自动证明 occurrence 解析重复或数据错误；生物学装配、链映射或沉积结构本身都可能形成这种现象。
- 当前 split 的六类统计来自 split JSON 内已经保存的 occurrence；本文没有改变、过滤或重新划分任何 split。
- 本文不实现类别标签、不决定 class ID 顺序、不决定 `other` 的训练映射，也不写发布门控。
