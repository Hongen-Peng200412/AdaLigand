# 配体语言模型产物字段参考

本文只用于按字段追错。处理主线见 [README.md](README.md)，真实样本逐步示例见 [真实样本端到端处理示例.md](真实样本端到端处理示例.md)，运行命令见 [README_run.md](README_run.md)。

点号表示 JSON 对象的逐层嵌套，例如 `diagnostics.clc.read.candidate_count` 表示先进入 `diagnostics`，再进入 `clc` 和 `read`，最后读取 `candidate_count`。

本文使用下列术语：

- PDB 是一份生物大分子三维结构记录；occurrence 是一个 PDB 中的一次配体出现，由
  `(pdb_id, candidate_id)` 唯一标识。
- SMILES 是用一行字符表示分子原子、化学键、分支和电荷的文本。CCD 是 PDB 化学组分
  字典中的单个标准组分；BRANCHED 是由多个残基分支连接的配体。
- LigandObject 是 Stage C 化学解析阶段保存的可复用配体模板。RDKit 是把 SMILES 转成
  分子图并重新生成字符串的化学软件包。mmCIF 是 PDB 三维结构记录的文本格式；
  pdbeccdutils 是读取该格式并处理化学组分的软件包；CLC 是它从完整 PDB mmCIF 文件中
  识别出的共价连接配体组分。
- `present_{candidate_id}` 是与 `LigandObject.atoms` 逐原子对齐的布尔掩码；`True` 表示
  当前 PDB 实际出现该模板原子，`False` 表示未出现。prepared 记录保存当前 occurrence
  最终准备出的模型 SMILES 和转换事实。
- JSONL 是“每个非空物理行保存一个 JSON 对象”的文本文件；NPZ 是按名称保存多个
  NumPy 数组的压缩文件。token 是模型词表中的一个文本片段，tokenizer 是把 SMILES
  拆成 token 并转换成编号的程序；batch 是模型一次共同计算的一组 occurrence。
- diagnostics 是只记录输入、转换和异常事实的诊断对象，不参与自动筛选；dtype 是
  NumPy 数组每个元素的数据类型。
- sanitize 是 RDKit 对价态、芳香性等化学属性的检查与整理；canonical SMILES 是按确定
  规则写出的统一字符串；isomeric 版本保留立体化学标记，non-isomeric 版本不保留。
- one-hot 是只有一个位置为 1、其余位置为 0 的类别向量；padding 是为让同一 batch 的
  短序列对齐长度而在末尾补入的占位内容。
- NaN 表示无法解释为普通有限实数的数值；Inf 表示正无穷或负无穷；CUDA 是 NVIDIA GPU
  执行模型计算所用的软件与设备接口。
- int32 是每个整数用 32 位保存的数据类型；float32 是每个浮点数用 32 位保存的数据类型。

## `prepared_smiles.jsonl`

每个非空物理行是一个完整 JSON 对象，对应一个五类正式 occurrence。

### 顶层字段

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `pdb_id` | 非空小写字符串 | 当前 `parse/{pdb_id}` 目录标识 |
| `candidate_id` | 非负整数 | 当前 PDB 内的 occurrence 编号 |
| `object_key` | 非空字符串 | LigandObject 模板键 |
| `kind` | 非空字符串 | 正式路径为 `CCD` 或 `BRANCHED` |
| `type_tag` | 字符串枚举 | 五类正式标签之一，不接受 `other` |
| `is_covalent` | 布尔值 | Stage C 保存的受体共价连接事实 |
| `smiles` | 非空字符串或 `null` | 交给模型公开接口的字符串；所有路径均未得到字符串时为 `null` |
| `smiles_source` | 字符串枚举 | `ccd`、`clc`、`present_graph`、`unsupported` 或 `occurrence_error` |
| `diagnostics` | JSON 对象 | 化学转换、输入缺失和异常事实；不自动筛除 occurrence |

`smiles_source=unsupported` 表示 occurrence 的 `kind` 不是 `CCD` 或 `BRANCHED`。`smiles_source=occurrence_error` 表示顶层身份字段已经足以写记录，但该 occurrence 的输入读取或化学处理抛出了未在内部吸收的异常。

### CCD diagnostics

以下字段位于 `diagnostics`。`raw_smiles` 和 `rdkit_parse_error` 在 `smiles_source=ccd` 时始终存在。CCD 的 LigandObject 读取或未在内部吸收的处理异常会改写为 `smiles_source=occurrence_error`，此时 diagnostics 只保证 `error`。

| 完整字段 | 类型与出现条件 | 含义 |
|---|---|---|
| `diagnostics.raw_smiles` | 字符串，允许空 | LigandObject NPZ 中的原始字符串去掉首尾空白后的结果 |
| `diagnostics.rdkit_parse_error` | 字符串或 `null` | `MolFromSmiles(..., sanitize=False)` 的异常或 `RDKit returned None`；原文为空或建图成功时为 `null` |
| `diagnostics.error` | 字符串；CCD 原文为空、`smiles_source=unsupported` 或 `smiles_source=occurrence_error` 时出现 | 说明空原文、不支持的 kind 或 occurrence 外层异常 |
| `diagnostics.used_raw_smiles` | `true`，条件出现 | RDKit 未产生非空 canonical non-isomeric SMILES，但非空原文仍交给模型 |
| `diagnostics.sanitize_error` | 字符串或 `null`，RDKit 建图后出现 | `Chem.SanitizeMol` 的异常 |
| `diagnostics.isomeric_smiles` | 非空字符串或 `null`，RDKit 建图后出现 | canonical isomeric SMILES |
| `diagnostics.isomeric_smiles_error` | 字符串或 `null`，RDKit 建图后出现 | 生成 isomeric SMILES 的异常 |
| `diagnostics.model_smiles_error` | 字符串或 `null`，RDKit 建图后出现 | 生成 canonical non-isomeric SMILES 的异常 |
| `diagnostics.stereo_removed` | 布尔值或 `null`，RDKit 建图后出现 | 两种非空规范字符串是否不同；任一缺失时为 `null` |

RDKit 建图后还会出现 `diagnostics.chemistry`：

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `diagnostics.chemistry.atom_count` | 整数 | 当前 RDKit 分子的原子数 |
| `diagnostics.chemistry.fragment_count` | 整数或 `null` | RDKit 识别的断开片段数 |
| `diagnostics.chemistry.fragment_count_error` | 字符串或 `null` | 片段统计异常 |
| `diagnostics.chemistry.has_disconnected_components` | 布尔值或 `null` | 片段数是否大于一；片段数未知时为 `null` |
| `diagnostics.chemistry.has_metal` | 布尔值 | 是否包含代码所列金属原子序数 |
| `diagnostics.chemistry.charged_atom_count` | 整数 | 形式电荷不为零的原子数 |
| `diagnostics.chemistry.total_formal_charge` | 整数 | 所有原子形式电荷的代数和 |

### BRANCHED 的 CLC diagnostics

`smiles_source` 为 `clc` 或 `present_graph` 时始终存在 `diagnostics.clc`。即使随后改用 present 后备图，CLC 的读取与选择事实也会保留。BRANCHED 的顶层输入异常若改写成 `occurrence_error`，diagnostics 只保证 `error`。

| 完整字段 | 类型与出现条件 | 含义 |
|---|---|---|
| `diagnostics.clc.read.candidate_count` | 非负整数 | 成功转换成项目候选的 CLC 数 |
| `diagnostics.clc.read.package_result_count` | 非负整数或 `null` | pdbeccdutils 原始返回数；整体读取失败时为 `null` |
| `diagnostics.clc.read.error` | 字符串或 `null` | mmCIF 预处理或整体读取异常 |
| `diagnostics.clc.read.candidate_warnings` | 对象列表 | 有警告的原始候选及包警告 |
| `diagnostics.clc.read.candidate_errors` | 对象列表 | 有包错误或转换异常的原始候选 |
| `diagnostics.clc.read.package_charge_and_bond_order_are_not_treated_as_authoritative` | `true` | 不把包给出的形式电荷和键级宣称为唯一化学真值 |

候选消息对象的完整路径为：

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `diagnostics.clc.read.candidate_warnings[*].candidate_index` | 非负整数 | 有警告候选在包返回列表中的零基序号 |
| `diagnostics.clc.read.candidate_warnings[*].messages[*]` | 字符串 | 该候选的一条包警告 |
| `diagnostics.clc.read.candidate_errors[*].candidate_index` | 非负整数 | 有错误候选在包返回列表中的零基序号 |
| `diagnostics.clc.read.candidate_errors[*].messages[*]` | 字符串 | 该候选的一条包错误或转换异常 |

| 完整字段 | 类型与出现条件 | 含义 |
|---|---|---|

## `results.jsonl`

每个非空物理行对应 prepared 文件中的同一个 candidate。

### 顶层字段与状态

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `pdb_id` | 非空小写字符串 | occurrence 所属 PDB |
| `candidate_id` | 非负整数 | occurrence 编号 |
| `type_tag` | 字符串枚举 | 五类正式标签之一 |

### MoLFormer diagnostics

诊断成功时保存以下完整字段；它们不参与筛选：

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `diagnostics.token_count_without_special_tokens` | 非负整数 | 化学 token 数 T |
| `diagnostics.token_count_with_special_tokens` | 非负整数 | 加入特殊 token 后的总长度 |
| `diagnostics.unsupported_tokens` | 字符串列表 | 已拆出但精确词表中不存在的去重 token |
| `diagnostics.unsupported_tokens[*]` | 字符串 | 一个精确词表中不存在的 token |
| `diagnostics.token_roundtrip_text` | 字符串 | 把化学 token 原序拼回的文本 |
| `diagnostics.token_roundtrip_matches_input` | 布尔值 | 拼回文本是否等于 prepared 字符串 |
| `diagnostics.exceeds_pretraining_length_reference` | 布尔值 | 总长度是否超过 202 token 参考长度 |
| `diagnostics.truncation_requested` | `false` | 正式 tokenizer 不请求截断 |
| `diagnostics.diagnostic_error` | `null` | 诊断成功 |

诊断失败时，diagnostics 只保证 `truncation_requested=false` 和非空的 `diagnostic_error`。官方 tokenizer 与模型仍会被调用。

### SMI-TED diagnostics

以下规范化与诊断状态字段始终存在：

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `diagnostics.public_api_input_smiles` | 非空字符串 | 传给官方 `model.encode` 的 prepared 字符串 |
| `diagnostics.official_normalized_smiles` | 非空字符串或 `null` | 独立调用官方规范化得到的字符串 |
| `diagnostics.official_tokenizer_input_smiles` | 非空字符串或 `null` | 可确认进入 tokenizer 的规范化字符串 |
| `diagnostics.official_normalization_success` | 布尔值 | 独立规范化是否得到非空字符串 |
| `diagnostics.official_normalization_error` | 字符串或 `null` | 独立规范化异常或空结果原因 |
| `diagnostics.token_diagnostic_error` | 字符串或 `null` | tokenizer 诊断异常；规范化失败或诊断成功时为 `null` |

规范化成功且 tokenizer 诊断成功时，另外出现：

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `diagnostics.token_count_without_special_tokens` | 非负整数 | 截断前化学 token 数 |
| `diagnostics.token_count_with_special_tokens_before_truncation` | 非负整数 | 加特殊 token 后、官方截断前的总长度 |
| `diagnostics.official_max_length` | 正整数 | 官方模型对象报告的最大长度 |
| `diagnostics.official_default_will_truncate` | 布尔值 | 截断前长度是否超过官方最大长度 |
| `diagnostics.diagnostic_token_prefix_within_length` | 字符串 | 按长度规则截出的诊断 token 前缀，不代表官方内部张量 |
| `diagnostics.unsupported_tokens` | 字符串列表 | 不在精确词表中的去重 token |
| `diagnostics.unsupported_tokens[*]` | 字符串 | 一个精确词表中不存在的 token |
| `diagnostics.unknown_token` | 字符串或 `null` | 官方 tokenizer 的未知 token |
| `diagnostics.pad_token` | 字符串或 `null` | 官方 tokenizer 的 padding token |
| `diagnostics.unknown_token_equals_pad_token` | 布尔值 | 两种 token 配置是否相同 |
| `diagnostics.token_roundtrip_text` | 字符串 | 截断前 token 原序拼回文本 |
| `diagnostics.token_roundtrip_matches_normalized_smiles` | 布尔值 | 拼回文本是否等于规范化字符串 |

规范化成功但 tokenizer 诊断失败时，上表字段不出现，只在 `token_diagnostic_error` 保存异常。公开 `model.encode` 仍会被调用。规范化失败的 occurrence 也不会被筛掉：它单独调用公开接口；官方报错时记录 `model_failed`，若仍返回向量则记录 `encoded` 且 `model_smiles=null`。

### encoded 向量有限性 diagnostics

本项目正式写入函数为每条 `status=encoded` 记录追加：

| 完整字段 | 类型 | 含义 |
|---|---|---|
| `diagnostics.all_finite` | 布尔值 | 768 个值是否全部有限 |
| `diagnostics.nan_count` | 非负整数 | NaN 数量 |
| `diagnostics.positive_inf_count` | 非负整数 | 正无穷数量 |
| `diagnostics.negative_inf_count` | 非负整数 | 负无穷数量 |

读取函数允许缺少这四项的既有产物进入汇总，使汇总可以把它们计入 `unknown`，而不是
误报为含非有限值。

NPZ 只在 `status=encoded` 时存在，并固定包含七个数组：

| 数组名 | dtype 与形状 | 含义 |

| `pdb_id` | 字符串标量 | occurrence 所属 PDB |
