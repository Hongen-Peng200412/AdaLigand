## Decisions

- **细分支（read-only）**:逐对全量 cross-attn,**Stage2 绝不写回共享 trunk**（错配对噪声会污染被全图复用的表示）;选项二 typed K/V + 装配 mask（`(PP,A)` 一套 K、PP/A 各自投影；A-only = mask 掉 PP）;learned-query 读出——**recall 配体当 query→1 码;precision PP、A 各当 query→2 码**（PP 只 attn CCD、A 只 attn CCD,PP/A 不互 attn）。
- **粗分支**:3 类 rep `pp_repr / a_repr / ccd_repr`;重复层 **Order B = 跨类 rep-rep cross-attn → 同类 self-attn（3 类各自做）**（competition 必须 match-aware,故跨类先于同类）;末尾一次 `rep × 跨类未塌缩实体` 出匹配描述。**Stage3 无粗分支**（单对无集合）。
- **粗分支 detach**:默认 detach（只读集合推理器,chunk 最省）;**"不 detach"已升格为有理由的可选主线**（§6.1,开关 `coarse_detach`）——理由="细分支不耦合给干净细节、粗分支耦合给全局,信息互补;不 detach 让全局先验反哺 trunk"。
- **丙**:不死守"查询数=码数=匹配描述数",打分 MLP 输入维自由拼接（3 类下其实自然对齐 recall1/precision2）。
- **打分**:粗码 + 细码 concat → 两个分参数 MLP → `coverage_recall/precision_logit`;主损失 = 软回归 + 阈值 focal + 身份内匈牙利。
- **两级辅助**:粗 rep 全局属性头（大小/形状/分子量/原子数,防塌缩）+ 细 ligand 复用 Emap2lig `AuxiliaryModule`（逐原子/键属性,可选）;去掉 `slot_is_present`;每个头标预期作用。
- **PP**:加 `density_point_ligand_area_probability` node 特征（对称于受体结合概率）;**PP 不做内部图 MP**,只"初始化 gather + 与 P 的 S 融合"。**A**:gated 消息传递 ~4 块（对齐 Emap2lig InstanceSeg num_blocks=4）。
- **表示前导**:迭代前先建好 PP/A/CCD 共享 trunk（之前漏了,已补 §4）。
- **chunk**:全局部分（压缩 + rep-rep）整图算一次并保留;逐对部分（细分支 + 粗末尾 rep×全实体）分 chunk + 梯度累积 → **全局视野 + 显存可控,粗分支即其实现机制**。
- **Stage2/Stage3 四处差别**:细分支输出（read-only→readout / writeback→扩散）;粗分支（有/无）;几何（无/有）;批量（`[n_blobs,n_slots]` 网格 / `[B_pairs]`×扩散步,context 缓存）。算子同一套。
- **工程形态**:不强求统一 Block,做**可配置大类**（`num_pairformer_blocks/num_A_graph_blocks~4/L_coarse/couple(int)/coarse_detach/粗分支开关/辅助头开关` 可调）。
- **Emap2lig 复用**:`PairFormer`（配体内部 import）、`SelectedCrossAttention`（跨集合适配 + typed K/V）、`AuxiliaryModule`（细 ligand 辅助）、`select_top_k_points`（PP gather）、`AtomDiffusion`（Stage3 扩散）;`SparseGraphInteraction` 自写（参照 PocketXMol NodeBlock,去坐标更新）。
