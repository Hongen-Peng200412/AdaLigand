# Handoff: Matcher 正式训练授权前收口

Date: 2026-08-04

## Current State

不依赖 Stage1 推理产物的 Anchor/A-only O/O′ Matcher 已完成实现、真实数据 smoke、FinePair 与建图等价加速、A800 显存画像和普通 Dataset 60 分钟吞吐画像。正式 Phase1/Phase2 训练尚未提交；下一个状态转换必须是用户审阅正式 YAML、shell 和无 `--time` 的 A800 提交命令后明确授权。

## Completed

- FinePair 保留完整 `C×S` 配对网格，改为 chunk 内联合批处理；符合条件时使用显式 varlen Flash Attention，其他情况回退 PyTorch scaled-dot-product attention。
- 分子图的边字段、RBF 和半径邻居选择已批量化；半径、最大邻居数、等距排序、化学边覆盖和 6 类标签不变。
- 完整 Matcher 回归为 42 项通过、1 项 Windows 无 CUDA 跳过；CUDA 服务器专项已确认 Flash 输出和梯度与 SDPA 等价。
- 普通 Dataset 画像首次因 DataLoader 默认共享策略耗尽文件描述符失败。当前 Anchor 的训练、吞吐画像和独立推理入口在 `num_workers>0` 时改用 `file_system`；修复后 708 步运行无同类错误。
- 60 分钟测量：708 steps、2,755 PDB、37,925 occurrence；5.0880 秒/batch、5.0606 秒/优化步、0.02744 秒/数据等待、1.3076 秒/PDB、0.09499 秒/occurrence。无 OOM，allocated/reserved 为 71.150/72.910 GiB。
- 真 `9cpk` 冻结样本：64 occurrence、177 候选、106,044 A 原子；组装 3.137 秒，优化步 9.476 秒，allocated/reserved 为 48.873/49.775 GiB，无 OOM。更重 `9kdv` 为 13.007 秒和 69.942/71.383 GiB。
- 无限时 A800 simple Job `335261` 已释放，终态 `COMPLETED 0:0`，没有正式训练任务在运行。

## Decisions

- 正式数值精度保持 BF16 autocast；损失与概率缩减保持 FP32。
- 正式 `map_channels=[24,48,72,96]`、`occurrence_budget_per_batch=64`、`map_candidate_chunk_size=64`、`fine_pair_chunk_size=2048`，并启用图 activation checkpoint。
- 正式长训练必须使用 release/launch 流程新提交 A800 Job，不得复用 simple 画像工作台，也不得设置 `--time`。

## Open Questions

- 60 分钟画像的 reserved 峰值 72.910 GiB 超过既定 72 GiB 人工门槛 0.910 GiB，但无 OOM 且距 79.325 GiB 物理上限仍有约 6.4 GiB。需要用户决定是否接受该小偏差并启动正式训练，或先下调 U-Net 通道重测。
- 完整训练集 epoch-0 候选准备约 59 分钟。这一次性/每 epoch 成本并未包含在 5.0880 秒/batch 中，正式时长估算必须单独计入。
