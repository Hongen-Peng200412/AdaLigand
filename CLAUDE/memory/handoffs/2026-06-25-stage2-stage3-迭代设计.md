## Decisions

- **匹配损失**：跨身份不用 DETR 匹配损失（GT 对应已知）；匈牙利只在**同身份 occurrence 内部**。主线 = Regime II（occurrence 级覆盖 α/β 对称 + 身份内匈牙利），第一版只实现"方案 1（早期 e_s、slot 独立 query）"。
- **预测对象**：双覆盖矩阵 `coverage_recall_logit`(A) / `coverage_precision_logit`(B)，per-cell sigmoid + 阈值 focal；A=配体当 query 配体侧池化，B=密度点当 query 密度侧池化（分参数分方向）。
- **count**：身份 token + 数量 N 可学习嵌入；硬 count 在解码期 top-k。
- **三层注意力**：level-1 簇内（配体=复用 Emap2lig PairFormer；密度点∪受体 = 异构稀疏图，gated 消息传递；受体带键∪radius，密度点默认无边）；level-2 配体↔context cross-attn 双向读出；level-3 全图 blob/slot 代表向量自注意 explaining-away + 实质参与监督（`blob_is_real_logit` 等）。
- **context 图算子** = `SparseGraphInteraction`（第一版仅 gated 消息传递 / PocketXMol 式；类型专属 Q/K/V 投影；**不更新坐标**；Stage2/Stage3 通用）；softmax 注意力版作消融。
- **反作弊**：blob 有位置、CCD 无位置；Stage2 跨集合 = 特征空间 cross-attn，Stage3 = 几何 cross-attn（配体有噪声坐标）。
- **复用 Emap2lig**：`PairFormer`（配体内部，直接 import）、`SelectedCrossAttention`（跨集合，适配）、`select_top_k_points`（PP 采样）、`AtomDiffusion`（Stage3 扩散头）。
- **批量无循环**：Stage2 在 `[n_blobs, n_slots]` 网格批量；Stage3 堆 `[B_pairs]` × 扩散步、context 缓存。
- **受体结合概率**：作受体 node 特征 + 辅助头 `binding_probability_logit` 反向监督（F1≈0.65>0.55）。
- **预训练化学 UNet**：独立小网、从头训、冻结、特征落盘；Stage2/3 共用。
- **几何注入**：默认加性相对位置偏置；3D RoPE 留钩子不实现；DiffDock 等变张量场排除（Stage2 预测不变标量、不需等变）。
- **数据/BOX**：Stage1 80³；Stage2/3 体素 48³ + 点云可到 80³ 按 pocket 过滤；必切 _C/bias/context，全图划窗推理（20–30d）后续与 Stage3 训练并行。
