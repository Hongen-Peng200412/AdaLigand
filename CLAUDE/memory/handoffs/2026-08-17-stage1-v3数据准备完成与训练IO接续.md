## Decisions

- 第三版训练使用同一个生产 `Stage1Dataset`/Loader 替换旧实现，不创建并存的 `Stage1V3Dataset`。被替代代码直接从活动树删除，历史只从 Git 读取。
- 训练保持全局 BOX 打散。按 PDB 分组训练已被证明会明显降低模型性能，不得恢复为活动入口。
- `.npy` 必须只读 mmap、按 rank/worker 延迟打开；热路径只检查元数据和实际 80³ 裁块，禁止扫描完整 mmap 数组。
- Dataset/Collator 分别传 `atom_feat float32 (N,49)` 和 `atom_is_backbone bool (N,)`；模型输入边界拼成 50 维。`receptor_tokens.npz` 不修改，旧 49 维检查点由模型配置兼容。
- `box_sample_fraction` 从 Dataset、请求持久化、配置、测试和文档完整删除；请求模块中仍供裁块/推理使用的通用类型继续保留。
- DataLoader 使用 `pin_memory=True`、`prefetch_factor=2`、`persistent_workers=False`。单卡 16 CPU 为 14 workers；双卡共 32 CPU 时每个 rank 为 14 workers。
- `protein`、`nucleic`、`distance` 三类结构 head 拆成独立开关。主链 U-Net 使用 `true/true/true`；无主链 U-Net 使用 `false/false/true`。无主链版本仍保留 binding receptor voxel 辅助损失和 ligand-distance 损失。
- 本轮只准备 Find_0/CPC1、Find_1/CPC1 和两套 U-Net；Find 不自动进入 CPC2。
- `训练与运行/sh/infer/` 不删除。删除旧 `stage1_box_pool.py` 前，必须把 `prepare_inference_pdb_lists.sh` 的 `_load_split_pdb_ids` 依赖迁移到新的只读接口。
- 正式训练不由当前任务提交。时间节点 1 验收后，用户会复制任务负责提交与监视；当前任务继续推理程序重构。
- 不建立 heartbeat。稳定运行后的监视使用命令自然等待，每 10 或 20 分钟检查一次。
- 用户明确反对代码目录膨胀和为极低概率情况堆叠过度防御逻辑。后续实现要保持正式契约、错误检查和原子性，但必须用少量职责清楚的模块完成，不能再复制一套 V3 类或制造凌乱脚本。
