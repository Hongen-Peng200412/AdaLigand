# Matcher v2 双模式实施中

## 当前目标

在 `codex/matcher-v2-dual-context` 实现一套共享 Matcher。`ground_truth_context` 读取真实配体、GT 配体 10 Å 受体包络 A 与中心 48³ 实验密度；`stage1_context` 额外读取 Find F1-centered 的 V、P、A 条件与完整图概率派生 PP。先把模式一训练、推理和评估跑通，再从模式一权重继续训练模式二。

## 已完成

- `matcher_v2/contracts.py` 把 Stage3 可复用的 `PocketInput` 与 Matcher 专属槽位/标签分开。
- 两个显式 Dataset 位于 `matcher_v2/data_ground_truth.py` 和 `matcher_v2/data_stage1.py`；没有 Dataset 注册器或通用多模态插件框架。
- `matcher_v2/model.py` 复用已验证的图、U-Net、TypedAttention、粗细 Block，实现六个独立预测头。A 的 Stage1 概率与特征形成逐原子增量；V/P/PP 形成 BOX 候选增量。两者末层均为零初始化，条件缺席时不经过增量网络。
- `matcher_v2/objectives.py` 实现 A/B/O 连续 SmoothL1、A′/B′/O′ focal gamma=2、身份内 Hungarian、深监督、实体辅助和 FinePair 辅助。
- `matcher_v2/decode_ground_truth.py` 在同一 PDB 内联合决定一对一匹配与空槽位；验证以 0.003 步长扫描解码后的 F1 与 PR-AUC，checkpoint 冻结阈值，独立评估不重新选择阈值。
- 正式配置位于 `configs/matcher_v2/mode1/`；正式脚本位于 `训练与运行/sh/matcher_v2/mode1/`，W&B online，脚本不设置 Slurm 时间限制。
- 本地新版加既有图/U-Net 共 22 项测试通过；覆盖完整模型严格零增量、Phase1→Phase2、Phase2 resume 冻结、同身份 occurrence 交换、六头 FinePair、PP 四尺度梯度和验证调度。训练入口已补充 BF16 验证、精确五次验证、在线 W&B、`events.jsonl`、resolved YAML 与断点续训。
- `matcher_v2/README.md` 已写明两个数据入口、当前模式一不启用自生成点，以及 Stage3 可直接复用的叶子。
