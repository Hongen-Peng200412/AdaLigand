## Decisions

- `ligand_dist.npz` 保存与实验密度网格对齐的 `float16` 原始 Å 距离；无配体原子时全为正无穷。
- 蛋白和核酸各使用一个固定 softmax，类别与损失定义见活动 ExecPlan。
- 新 Find_1 使用 64 通道 `voxel_final`、关闭 RAUNet 末端多尺度输出块，并运行完整 CPC1→CPC2。
- 五项损失权重按配体区域、受体结合区域、配体反距离、蛋白原子、核酸原子顺序固定为 `1.0:0.1:0.3:0.05:0.05`。
- Find_1 受体特征写入复现旧 Job `321540`：sigma=0.7 的 `3×3×3` Gaussian scatter 优先于配置中同时保留的 soft 开关。
- Find_1 CPC1、CPC2 最高学习率为 `5e-5`；新版 `unet_c1` 最高学习率仍为 `1e-4`。
- Find_1 CPC1 与 `unet_c1` 的优化器学习率 warmup 比例统一为 `0.005`；Find_1 CPC2 继续无 warmup。
- 距离标签生产同时运行最多 192 个 CPU 核；正式 GPU 训练只接管 Job `321540`。
- 一个受限 subagent 负责快照推理、正式产物可变通道与 Selector 惰性输入；主 agent 负责接口、审查和合入。
- 复用 Job `321540` 时必须显式设置唯一 `POCKET_RUN_STAMP`，先证明新运行目录与旧 `job321540` 目录不同，再允许触碰 `kill_lock`；不得覆盖旧快照或放宽拒绝覆盖保护。
