# Handoff: Stage1 V3 tune 统一预过滤

Date: 2026-08-22

## Current State

Stage1 V3 的 basic 与 Gaussian tune 现在共用显式 `prefiltered_min_voxel`。该门槛在任何参数尝试前固定；体素数不足的候选保持未入选，但候选所属 PDB 与全部真实 occurrence 仍保留在评估事实中。

## Completed

- `tune` 新增必填 `--prefiltered-min-voxel`。
- `F{alpha}_basic.json` 与 `F{alpha}_gaussian.json` 分别保存固定 `prefiltered_min_voxel` 和搜索所得 `min_voxels`。
- basic 阈值扫描与 Gaussian 全部参数组合共同应用预过滤；两个门槛互不限制。
- centered 首次评分、score-only 与 evaluate 同时应用分数阈值和两个体素数门槛。
- 推理配置采用主工作树当前值：完整图窗口 batch 16，centered batch 8；README 另列 A100 对应值 8 和 4。
- CPU 回归 35 passed；Windows RTX CUDA smoke 2 passed；编译、配置解析、五个 CLI 帮助和差异检查通过。

## Decisions

- 预过滤不裁剪 centered 或 blobs 候选轴，不重写 ragged offsets，也不增加候选适配类。
- `prefiltered_min_voxel > min_voxels` 是合法组合；较小的 `min_voxels` 尝试只是冗余计算，不是错误。
- 不合格候选固定为未入选，因此不会成为 FP；如果它覆盖真实 pocket，未命中的 occurrence 仍按既有指标贡献 FN。

## Next Actions
