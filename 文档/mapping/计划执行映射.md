# 计划执行映射

本文件是 AdaLigand 的 plan-centric 文档索引，用来说明计划书、执行日志、代码/契约文档和开放问题之间的关系。它不是决策日志、产物清单或详细漂移记录；这些内容应放在 `文档/exec_plan/`、代码旁契约 README 或 Git 历史中。

## 文档分层与文件夹语义

- **规划文档 `文档/规划文档/`** = 内容已稳的 clean spec；**讨论 `文档/讨论/`** = 内容仍在演进的规划稿（中性名，不含"过时/未成熟"含义）。**成熟度以本 mapping 的「位置·状态」列为准**；一份文档 churn 停下后再搬进 `规划文档/` 并翻状态。
- **执行日志 `文档/exec_plan/`**（过去时，记实现/决策/验证）、**契约 README**（代码旁，记当前接口现实）、**本 mapping**（meta 层，链接一切）。
- **跨文档边界"谁 owns 谁"就地声明在各文档头部**（每份文档头写清"我 owns X、不 owns Y、权威层级"）；本 mapping 只做索引与关系，**不承载边界规则正文**，不做决策日志/产物清单。`AGENTS.md` 只保留一行指向本文的指针，不承载易变内容。
