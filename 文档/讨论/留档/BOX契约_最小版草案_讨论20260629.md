## 0. 本版收敛要点（相对原契约的差异，仅供核对）

1. **行 = 有 main_blob 的 box；没有 blob 的 box 不进训练**（直接丢，不留空行）。
2. **列 = 整张图的全部 occurrence**（Stage2 的输入：候选身份 × count），是图级固有属性，**与 box 怎么切无关**。
3. **每个 box 只钉 `main_blob`（≤1）+ `main_occurrence`**；`member_occurrences`、非 main 的 blob、稠密 α/β 矩阵——**都不记录/不落盘/不计算**。
4. **α/β/O 是派生量**：在 **Stage1 落 blob 时顺手算**它对**同样本 GT occurrence** 的覆盖，**稀疏落盘**（只存有覆盖的条目）。O-distance 由 box 中心 + occurrence 质心随时现推，不入盘。
5. **口袋以 blob 为锚**（密度档：blob 包络选受体原子，训练/推理同源）；纯受体档无 blob，以 box 中心为锚。
6. **UNet 特征按 box 落、只落"预测 ligand-area 之内"、且完整不截断**（top-k 与灌不灌背景是运行时的事，不烤进存储）。
7. **来源无关**：center / bias / context / infered_box 统一走同一份描述子 + 添油 schema（"换来源不动模型"）。
8. **context 不需要 clean 旗**：只按受体原子比率过滤选取；真撞上配体，覆盖几何会如实给出非零条目。
9. **不落盘 `diff`**（exp − sim 现场算）；**exp/sim 整图落盘、已重采样到 1Å**。

## 4. 第 3 层：per-box 添油（重订，最小集）

### 4.1 `main_blob`（Stage1 box 级推理产出）

| 字段 | 形式 | 说明 |
|---|---|---|
| `blob_mask` | ragged 体素 mask（COO/offset） | 已过 binding 概率硬过滤（§8 开放线程） |
| `blob_voxels` | int | `|b|`，供 α/β/O 派生 |
| `prompt_point` | `[3] float` | blob ligand-area mask 质心 → 交 Stage3 |
| `provenance` | dict | Stage1 checkpoint、阈值、过滤参数 |

> 一个 box 至多一个 main_blob；为 0 时该 box 不进训练（§0.1）。box 级推理时 main_blob = **离 box 中心最近**的 blob；全图推理时一个 blob 一个 box、不涉挑选。

### 4.2 覆盖（稀疏 α/β/O，落 blob 时顺手算）

| 字段 | 形式 | 说明 |
|---|---|---|
| `coverage` | list of `{candidate_id, inter_voxels}` | **只存与本 blob 有交的 GT occurrence**（多数 1 条，merge 2+ 条） |

派生关系（不另存）：
- `α = inter_voxels / |g|`（recall，`|g|` 来自 `mask_{cid}`）
- `β = inter_voxels / |b|`（precision，`|b| = blob_voxels`）
- `O_IoU = inter_voxels / (|b| + |g| − inter_voxels)`
- `O_dist = 1[ dist(box 中心, centroid_{cid}) < ρ ]` —— 纯受体档用，**完全现推、不入盘**

### 4.3 `ligand_area` 内 UNet 特征（按 box、完整不截断）

| 字段 | 形式 | 说明 |
|---|---|---|
| `la_voxel_index` | ragged `[K,3]` | **预测 ligand-area 之内**的体素索引，**完整存**（K 可变） |
| `la_voxel_feat` | ragged `[K, C_total]` | 两源堆叠：Stage1 UNet `voxel_final_feat` ⊕ 预训练化学 UNet 特征 |

> PP 采样运行时从这里 top-k（加 min 兜住小 blob）；**灌不灌背景是一个运行时开关，不在落盘层决定**。Stage1 UNet 很重、不能现场算，故必须落；只落 ligand-area 内把体量从"整图几十 TB"压到"单位数 TB"。

### 4.4 存储布局（治文件数，沿用原契约 §4.1）

`addons/{addon_name}/{pdb_id}.npz`：一个 PDB 所有 box 在该添油上的条目聚成一个文件；变长内容（blob mask / la_voxel_*）用 offset/ragged。加新添油 = 新建目录，老添油不动。

## 5. 第 4 层：现场算

- **56 维辅助密度通道**：从 exp/sim 在线算（原契约 §5.1）。
- **`diff`**：`exp − sim` 现场算。
- **O-distance**：box 中心 + occurrence 质心现推。
- **覆盖矩阵装配**：见 §6。

## 6. 矩阵装配（featurizer 职责，非落盘）

```text
对一张图 P：
  行 = 收集 P 的所有 box 的 main_blob（无 blob 的 box 已不在样本里）
  列 = P 的全部 occurrence（候选身份 × count 展开成 slot；图级，与 box 无关）
  entry(行 i, 列 j):
     读 box_i 的稀疏 coverage → 命中 j 则取其 α/β/O_IoU；未命中 = 0（拒假阳负监督）
     纯受体档：用 O_dist(box_i 中心, occ_j 质心)
  → [n_blobs, n_slots] 网格
```

> off-diagonal（merge、负样本）天然可算：只需 `main_blob_i` 与 `occurrence_j` 各自的量，**不需要任何 box 级交叉记录**——这正是 member 多余的原因。

## 7. box 家族（来源无关枚举）

| box_type | 来源 | main_occurrence | 备注 |
|---|---|---|---|
| `center` | occurrence mask 质心严格居中 | 有 | 正样本 |
| `bias` | center 偏移，每 instance 多个 | 有 | 偏移配方见下 |
| `context` | 受体原子比率 > 阈值的随机裁剪 | null | 假阳来源；**只按受体比率过滤，无 clean 旗** |
| `infered_box` | 全图划窗推理：一个 blob 一个 box | null | 真实分布；与 GT 关系由 §4 覆盖条目事后给出 |

**bias 偏移配方（提前切、冻结）**：
```text
1. 采样概率场 = 高斯衰减(从 GT ligand-area 中心) ∩ ligand-area（区域外为 0）
2. 在该场里采一点，取其相对中心的位移 d
3. 偏移 = 比例 × d + floor，floor ~ 某固定分布的随机量（保证小配体也有非平凡偏移）
   - 比例项随配体尺寸自适应（支撑集就是配体区域）；比例/分布的具体数值待标定
4. clamp 保证配体仍在 box 内
```

## 8. 上游开放线程（pipeline，非本契约，但卡着它的产出）

1. **阈值标定**：Stage1 似乎要**先全图推理一部分调阈值**，再用该阈值做 box 级推理的 blob 产生与落盘。（早晚要单独细谈。）
2. **blob 级硬过滤**：Stage1 推理时考察 blob 周围受体原子的 binding 概率 → 重打分 → 去掉低分 blob；落盘的 main_blob 是过滤后的。
3. **Stage1 推理重写**：训练/推理**共用同一套 dataset/builder**（数据读取、box 切、特征装）；修 CPU 并行（DataLoader worker / 预处理与 GPU 重叠 / 划窗批量流水）；砍不需要的多分类头。落盘 schema 与本契约一起定，别让推理程序自拍格式。
4. **时序**：契约现在定；执行要等数据集 D–G 完、Stage1 在新数据重训完。
