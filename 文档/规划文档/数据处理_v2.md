# AdaLigand 数据处理实现计划 v2（纯数据 · 代码级）

> **定位**：本文是「数据从哪下、怎么处理、每步产物什么形式、落在哪」的**可直接写代码的实现规范**。工程师 / AI agent 据此应能无歧义实现整条数据侧。
> **边界**：本文产物到「整图级 / occurrence 级」为止，**不切 BOX**；模型阶段另行规划。旧版数据处理调研文档仅作历史背景，不作为当前实现规格。
> **权威层级**：实际代码 > 配置/checkpoint > 真实产物与日志 > 本文。

## §0 总流水线与产物总览

主键贯穿全程：**`(pdb_id, candidate_id)` + 共享世界坐标系（map 世界坐标，Å）**。`pdb_id` 一律小写存储。

| Stage | 脚本 | 输入 | 产物（形式） | 落盘位置（`${ROOT}=…/AdaLigand`） |
|---|---|---|---|---|
| A 枚举 | `a_enumerate.py` | RCSB Search API | `pair_list.jsonl` | `${ROOT}/raw/pair_list.jsonl` |
| B 下载 | `b_download.py` | pair_list | mmCIF / map.gz / meta.json / CCD | `${ROOT}/raw/{rcsb_mmcif,emdb_maps,ccd_cache}/` |
| C 解析 | `c_parse.py` | mmCIF(+CCD) | `occurrences.jsonl` / `receptor_tokens.npz` / `ligand_coords.npz` / `ligand_objects/*.npz` | `${ROOT}/parse/{pdb_id}/…`、`${ROOT}/ligand_objects/` |
| D 原子标签 | `d_atom_labels.py` | C 产物 | `atom_labels.npz` | `${ROOT}/labels/{pdb_id}/atom_labels.npz` |
| E 密度+体素标签 | `e_density.py` | map + 去配体受体 + C | `exp/sim/diff/ligand_area.npz` | `${ROOT}/density/{pdb_id}/…` |
| F 质量 | `f_quality.py` | map + 模型 + meta | `quality.jsonl` | `${ROOT}/quality/{pdb_id}.jsonl` |
| G 过滤 | `g_filter.py` | F | `keep_list.jsonl` | `${ROOT}/keep_list.jsonl` |

各 Stage 独立分片并行；阶段间唯一耦合 = 世界坐标系 + `(pdb_id, candidate_id)`。

| D25 | 结合阈值 4Å 单值（可配）；ligand-area 半径 1.7Å（可调） |

## §2 全局约定（所有脚本共用）

### 2.1 坐标系 / 网格
- 复用 `mrc_tools` 逻辑（**逻辑参考、自己重写一份 `adaligand/io/mrc.py`**）：
  - `load_map(path) -> (grid(Z,Y,X) float32, voxel_size(3,) Å, origin(3,) Å)`：轴按 `mapc/mapr/maps` 重排到 ZYX；`origin = header.origin + nstart×voxel`（Å）。
  - `make_model_grid(grid, voxel_size, origin, target=1.0) -> (grid, voxel_size, origin)`：傅里叶 rescale + 补立方 + 平移 origin。
  - `world_to_voxel(coord, origin, voxel) = floor((coord-origin)/voxel)`（int, 顺序 z,y,x）。
- 网格轴序统一 **`(C,Z,Y,X)`**。

### 2.2 主键 / 命名
- `pdb_id` 小写；`candidate_id` int ≥0；`object_key` 见 §5.2。

### 2.3 序列化（B6）
```python
def save_npz(path, **arrays):   # 原子写、不压缩
    tmp = path + f".tmp.{os.getpid()}"
    np.savez(tmp, **arrays)     # 注意: 不是 savez_compressed
    os.replace(tmp + ".npz" if not tmp.endswith(".npz") else tmp, path)  # 处理 np 自动加 .npz
```
- jsonl：每行一个 JSON 对象，UTF-8，`ensure_ascii=False`。

### 2.4 并行契约（B7，每个 stage 脚本都实现）
```text
CLI 通用参数:
  --root PATH                # ${ROOT}
  --part_id INT --total_parts INT   # SLURM --array 数据分片（默认 0/1）
  --n_jobs INT               # joblib loky 多核（默认 -1 全核）
  --overwrite / --no-overwrite      # 默认 skip-if-exists
机制:
  items = enumerate_items(); items = shard(items, part_id, total_parts)
  Parallel(n_jobs, backend="loky", verbose=10)(delayed(process_one)(x) for x in items)
  process_one 内部: skip-if-exists（除非 overwrite）+ 原子写 + try/except 写失败报告、不抛
```
- 提供 `sbatch/*.sbatch` 模板：`#SBATCH --array=0-(N-1)`，内部传 `--part_id $SLURM_ARRAY_TASK_ID --total_parts N --n_jobs $SLURM_CPUS_PER_TASK`。

### 2.5 复用 Emap2lig 配体流水线
`process_molecule` / `process_branched_ligand` / `Atom`/`Bond` dtype / `LigandObject` 字段沿用 Emap2lig 血统（但用 §2.3 不压缩落盘，不调用其自带 `savez_compressed`）。CCD reference Mol 使用本地 per-CCD pkl 缓存，缺失时从 RCSB ligand-CIF 获取并缓存；不使用 bulk CCD 字典主路径。

## §3 Stage A — 样本宇宙枚举（`a_enumerate.py`）

**RCSB Search API**（`POST https://search.rcsb.org/rcsbsearch/v2/query`）查询（terminal 组合，AND）：
```json
{"query":{"type":"group","logical_operator":"and","nodes":[
  {"type":"terminal","service":"text","parameters":{"attribute":"exptl.method","operator":"exact_match","value":"ELECTRON MICROSCOPY"}},
  {"type":"terminal","service":"text","parameters":{"attribute":"rcsb_entry_container_identifiers.emdb_ids","operator":"exists"}},
  {"type":"group","logical_operator":"or","nodes":[
    {"type":"terminal","service":"text","parameters":{"attribute":"rcsb_entry_info.nonpolymer_entity_count","operator":"greater","value":0}},
    {"type":"terminal","service":"text","parameters":{"attribute":"rcsb_entry_info.branched_entity_count","operator":"greater","value":0}}
  ]}
]},"return_type":"entry","request_options":{"return_all_hits":true}}
```
- 返回 PDB id 列表。逐条取 `rcsb_entry_container_identifiers.emdb_ids`（可能多个）→ **主 EMDB = 该 PDB 作为拟合模型对应的那个**。若只有一个 EMDB id，直接使用；若有多个，读取 EMDB `/entry/{emdb_id}` metadata，优先选择 `crossreferences.pdb_list.pdb_reference[].pdb_id` 明确等于当前 PDB 的 EMDB；无明确匹配时回到 RCSB 列表首个。
- 宽门 ligand 过滤在 Stage C 精确化；此处只要 `nonpolymer_entity_count>0`（branched 由 `branched_entity_count` 补充，二者任一 >0）。

**产物 `raw/pair_list.jsonl`**（一行一对）：
```json
{"emdb_id":"EMD-12345","pdb_id":"7abc","resolution":2.9,"resolution_info":{"selected":2.9,"status":"multi_candidate_consistent","selected_source":"emdb.final_reconstruction","selection_rule":"emdb_unique_preferred","n_candidates":2,"n_unique_values":1,"rcsb_disagree":false,"candidates":[{"source":"emdb.final_reconstruction","value":2.9,"units":"A","method":"final_reconstruction","path":"structure_determination_list...resolution.valueOf_"}]}}
```
`resolution` 是后续 Stage F/G 可直接消费的简化字段。`resolution_info` 记录候选来源、选择规则和状态：优先使用 EMDB final reconstruction；RCSB `rcsb_entry_info.resolution_combined` 只作 fallback 和一致性校验。常见状态包括 `single_unique`、`multi_candidate_consistent`、`ambiguous_emdb`、`fallback_rcsb`、`rcsb_disagree`、`missing`。每次枚举同时写 `reports/resolution_summary.json`，汇总本批样本的 resolution 状态分布。

## §4 Stage B — 下载（`b_download.py`）

| 资源 | URL | 产物 | 位置 |
|---|---|---|---|
| mmCIF | `https://files.rcsb.org/download/{PDB}.cif`（大写 PDB） | `{pdb_id}.cif` | `raw/rcsb_mmcif/` |
| EMDB map | `https://ftp.ebi.ac.uk/pub/databases/emdb/structures/EMD-{id}/map/emd_{id}.map.gz` | `emd_{id}.map.gz` | `raw/emdb_maps/` |
| 元数据 | `https://www.ebi.ac.uk/emdb/api/entry/{EMD-id}` | `{pdb_id}.meta.json` | `reports/meta/`（辅助；含 resolution 候选来源、recommended contour、PDB crossreference 等） |
| CCD | `get_ccd_mol(code)`（按需，pkl→RCSB ligand-CIF） | `{CCD}.pkl` | `raw/ccd_cache/` |

- 下载：3 次重试 + 指数退避；校验非空 / gzip 完整。`b_download.py` 默认下载 `mmcif,meta,map`，小样本验证可通过显式 `--resources mmcif,meta` 跳过 map。
- 失败写 `reports/_failed_download.jsonl`：`{"pdb_id":…,"resource":"mmcif|map|meta","error":…}`，不阻塞。

## §5 Stage C — 第一层统一解析（`c_parse.py`，核心）

用 `gemmi.read_structure` 读 mmCIF；**用沉积态非对称单元、`structure[0]`（第一个 model）、不做对称/assembly 扩展**（B5）。同时用 `gemmi.cif.read` 取 `_struct_conn` / `_pdbx_branch_scheme` / `_pdbx_entity_branch_link` / `_entity` / `_chem_comp` 表。可选 category 缺失时返回空表；真正的 category 读取异常不得吞掉，应暴露为解析失败。

### 5.1 junk 排除集（写死常量 `JUNK_RESNAMES`）
```
水/重水: HOH WAT H2O DOD
溶剂/添加剂: GOL EDO MPD PEG PG4 P6G TRS MES HEP ACT CIT EOH MOH IPA DMS DTT BME BU1 TBU
占位: UNX UNL UNK
惰性气体: XE KR
```
（来源 Make_Data `DEFAULT_EXCLUSION_RESNAMES`，可在 config 增删。）

### 5.2 C1 occurrence 解析 → `parse/{pdb_id}/occurrences.jsonl`

```text
1. 收集候选原子集合 HET = {所有 group_PDB==HETATM 或 entity.type in (non-polymer, branched) 的重原子},
   去掉 resname ∈ JUNK_RESNAMES；去掉与主链共价的修饰残基(归受体)。
2. 建并查集 UF over HET 原子。加边(共价, D24):
   a) CCD 模板内部键: 对每个残基, 取 get_ccd_mol(resname) 的 bond 列表, 按 atom_name 连其原子。
   b) _struct_conn 行 conn_type_id=='covale' 且两端都在 HET → union。
   c) _pdbx_entity_branch_link → union(糖链残基间)。
   * 排除 metalc/hydrog/saltbr。
   * covale 一端在聚合物(受体)残基 → 不 union, 给该组分置 is_covalent=True。
3. 连通分量 = occurrence。每个组分:
   - components = 该组分涉及的残基, 各记 (ccd_id, label_asym_id, label_seq_id, auth_asym_id, auth_seq_id, icode);
     组分内残基排序键 = (label_asym_id, label_seq_id)。index 从 1。
   - inter_bonds = 组分内"跨残基"的共价边, 表示成 [res_i_index, atom_i_name, res_j_index, atom_j_name]。
   - type_tag = derive_tag(components, entity, chem_comp)（见 5.3）。
   - 属性: is_covalent, polymer_length(组分残基数), n_heavy_atoms。
4. candidate_id: 全部 occurrence 按 (组分最小 label_asym_id, 最小 label_seq_id, 最小 atom serial) 排序, 0-indexed。
```

`derive_tag`（5.3，B3）：
```text
若 entity.type=='branched' 或所有残基 chem_comp.type 含 'SACCHARIDE' → 'sugar'
elif 任一残基 chem_comp.type 含 'PEPTIDE LINKING' → 'peptide_like'
elif 任一残基 chem_comp.type 含 'NA LINKING'(RNA/DNA) → 'nucleotide_like'
elif 单原子 且 element ∈ METAL_ELEMENTS → 'ion'
elif 所有残基 chem_comp.type=='NON-POLYMER' → 'small_molecule'
else → 'other'
```

**`occurrences.jsonl` 每行**：
```json
{"pdb_id":"7abc","candidate_id":1,"kind":"CCD|BRANCHED","object_key":"…","type_tag":"sugar",
 "is_covalent":false,"polymer_length":3,"n_heavy_atoms":42,
 "components":[{"index":1,"ccd_id":"NAG","label_asym_id":"E","label_seq_id":1,"auth_asym_id":"B","auth_seq_id":601,"icode":""}],
 "inter_bonds":[[2,"C1",1,"O4"]]}
```

### 5.2′ C2 LigandObject 物化 → `ligand_objects/{object_key}.npz`

- `object_key`：单残基 = `CCD:<ID>`；多残基 = `BRANCHED:<comp ccd 序, '-' 连>:<bond_hash>`，`bond_hash = md5(sorted(inter_bonds) + comp 序)[:6]`。
- **全局去重**：若文件已存在则跳过（同 object_key 跨所有 PDB 只算一次）。
- 单 CCD：`m=get_ccd_mol(ccd); m=RemoveHs(m); process_molecule(m,…)`。
- BRANCHED：逐 component `get_ccd_mol` → 按 components 顺序拼 atoms/bonds → 追加 inter_bonds → `process_branched_ligand`。
- **落盘 = LigandObject 字段（不压缩，§2.3）**：`atoms`(Emap2lig `Atom` 结构化 dtype)、`bonds`(`Bond` dtype)、`atom_names(object S4)`、`residue_names(object)`、`smiles(str)`、`name=object_key`、`blobs=None`。单 CCD 的 `residue_names=[ccd_id]`；BRANCHED 的 `residue_names` 为 components 的真实 CCD 序列。落盘文件名使用 safe object name，即把 `object_key` 中路径敏感字符转义后的文件名形式。
- BRANCHED 物化时，跨残基键端点 atom name 必须能在对应 residue 的 LigandObject 原子中找到；找不到即 fail-fast，不写出缺键对象。

### 5.3′ C3 受体 token 表 → `parse/{pdb_id}/receptor_tokens.npz`

- 受体原子 = `entity.type=='polymer'` 的重原子；排除水、ligand occurrence 原子、游离离子；共价修饰残基留作受体。
- altloc：每原子取空/A/1（按序首个）。
- 字段（逐数组、不压缩）：
```text
coords        (N,3) float32   世界坐标
element       (N,)  uint8      原子序数
res_type      (N,)  uint8      残基类型 id（见 RES_VOCAB）
is_backbone   (N,)  bool       原子名 ∈ {N,CA,C,O}(蛋白) / {P,O5',C5',C4',C3',O3'}(核酸)
atom_name     (N,)  S4
res_index     (N,)  int32      残基全局索引(0..)
chain_index   (N,)  int32
```
`RES_VOCAB`（固定顺序，写死）：`[ALA,ARG,ASN,ASP,CYS,GLN,GLU,GLY,HIS,ILE,LEU,LYS,MET,PHE,PRO,SER,THR,TRP,TYR,VAL, A,C,G,U,DA,DC,DG,DT, UNK]`（修饰残基映射到其标准母体；无法映射→UNK）。

### 5.4 C4 per-occurrence GT 真实坐标 → `parse/{pdb_id}/ligand_coords.npz`

对每个 occurrence，把 `_atom_site` 真实重原子对齐到该 occurrence 的 **LigandObject 原子索引**（B4）：
```text
1. 逐残基按 (component.index, atom_name) 精确匹配 LigandObject.atom_names + residue_id。
2. 沉积里缺的模板原子 → is_present=False（合法）。
3. 若存在无法映射到 LigandObject 的沉积原子 → 该 occurrence resolve_failed（写失败报告, 不落盘该 occurrence）。
   * 不设容差百分比: 要么全部映射(含缺失标记), 要么整条作废。
```
产物（每 occurrence 两数组）：`coords_{cid} (M,3) float32`、`present_{cid} (M,) bool`（M = LigandObject 原子数，行序对齐 LigandObject；缺原子坐标填 `nan` 且 present=False）。

## §6 Stage D — 第二层原子级标签（`d_atom_labels.py` → `labels/{pdb_id}/atom_labels.npz`）

```text
rec = receptor_tokens.coords (N_rec,3); lig = 所有 occurrence 的 present 真实坐标 (拼接, 记每原子所属 cid)
tree = cKDTree(lig)
d, idx = tree.query(rec, k=1)
binding_atom = d <= 4.0                      # D25 单值, config 可改
instance_id  = where(条件?, lig_cid[idx], -1) # 独占: 取最近 ligand 原子的 cid; 背景 -1
nearest_dist = d
```
字段：`binding_atom (N_rec,) bool`、`instance_id (N_rec,) int32`、`nearest_dist (N_rec,) float32`。
- class 不固化；`class_mapping.yaml`（`type_tag→class_id|ignore`）训练期驱动。默认配置随附 `${ROOT}/class_mapping.yaml`。

## §7 Stage E — 第三层密度 + 体素标签（`e_density.py` → `density/{pdb_id}/`）

### E1 实验图 `exp.npz`
```text
grid,vs,org = load_map(emd_{id}.map.gz 解压)
grid,vs,org = make_model_grid(grid,vs,org,target=1.0)
save: grid(1,D,H,W)float32, voxel_size(3,), origin(3,), contour(float, from meta)
```
存原始（不归一化、不压缩）。

### E2 模拟图 `sim.npz` + 差异图 `diff.npz`（Chimera，B2）
```text
1. 写去配体受体 CIF: 复制 mmCIF, 删除所有 occurrence 残基(及水/junk), 留 polymer + 共价修饰受体残基。
2. Chimera 命令(headless `chimera --nogui --script` 或 batch .cmd):
     open {receptor_stripped.cif}; open {emd_map}; volume #1 step 1
     molmap #0 {resolution} onGrid #1; volume #2 save {sim.mrc}; close all
   resolution 取 meta（缺失用一个保守默认, 记录）。
3. sim = load_map(sim.mrc) → make_model_grid(target=1.0)（与 exp 同网格）
4. diff = exp.grid - sim.grid
save sim.npz / diff.npz: grid(1,D,H,W)float32, voxel_size, origin
```
- 训练用真实受体；推理需 cryoatom 受体（域差记录在案）。

### E3 体素 ligand-area + 质心 `ligand_area.npz`
```text
centers = 所有体素中心世界坐标(D*H*W,3)；tree=cKDTree(centers)
对每个 occurrence o:
   near = tree.query_ball_point(o.present_coords, r=1.7)   # D25 半径可调
   mask_o = 并集体素; centroid_o = mean(其体素中心)         # = recrop 中心口径量
union_mask = ∪ mask_o
save: union_mask(1,D,H,W)bool, centroid_{cid}(3,)float32, [可选 mask_{cid} 稀疏(coo indices)]
```

## §8 Stage F — 质量度量（`f_quality.py` → `quality/{pdb_id}.jsonl`）

- **全局分辨率**：取 meta `resolution`。
- **Q-score（MapQ via Chimera，B1）**：
```text
chimera --nogui 跑 MapQ(mapq_cmd): 输入 (emd_map, pdb_model) → 输出逐原子 Q (写 cif/txt)
解析逐原子 Q → 按 occurrence(用 C 的 components 残基集合) 聚合: q_score = mean(该 occurrence 重原子 Q)
LIVQ: 留接口, 一期 null
```
- 每行：
```json
{"pdb_id":"7abc","candidate_id":1,"q_score":0.78,"livq":null,"map_resolution":2.9,"n_present":40}
```
- **先算分布、不预设阈值**。

### §8.1 Stage G — 过滤（`g_filter.py` → `keep_list.jsonl`）
- 看 `q_score`/`resolution` 分布后定阈值（软全局分辨率门 + 硬 per-occurrence Q-score 门），输出保留的 `(pdb_id, candidate_id)`。阈值见 §11。

## §10 QC 与失败处理

`reports/{pdb}.json` 逐样本检查：
- 每 occurrence 的 component CCD 可解析；`inter_bonds` 端点 atom_name 存在。
- LigandObject 原子数 == `ligand_coords` 行数；`present` 数量合理（`n_present/n_heavy ≥ 阈值`，如 0.5，否则记 `low_completeness`）。
- `exp/sim/diff/ligand_area` 同 `(D,H,W)`、同 `origin/voxel_size`、轴序 `(C,Z,Y,X)`。
- Chimera `.err` 仅可接受 warning（无 `No such file/open failed/No atoms/Error/Traceback`）。
- 失败类型枚举：`download_failed / parse_failed / resolve_failed / ccd_failed / chimera_failed / mapq_failed`；写报告、不阻塞分片。
- `reports/summary.json` 汇总各 stage 计数与失败分布。

## §11 待定参数（数据侧，config 暴露）

1. **Q-score 阈值 / 全局分辨率门**（Stage G）：先看分布再定。
2. **LIVQ** 是否启用（默认只 Q-score）。
3. **目标 voxel size**：默认 1.0Å（1.5Å 备选）。
4. **配体类型范围**：默认全部非 junk occurrence 入库 + `type_tag`，训练经 `class_mapping` 取子集（如 `ion→ignore`）。
5. **结合阈值 4Å / ligand-area 半径 1.7Å / 完整度阈值 0.5**：默认可用。
6. **molmap 缺分辨率时的保守默认**。
