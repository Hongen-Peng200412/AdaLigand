# AdaLigand 模型总规划（Find / Match / Build + BOX）

> **定位**：三阶段模型与 BOX 切分的总计划与决策记录。数据侧（下载/解析/标签/密度/质量，到「整图级/occurrence 级」为止）见 `数据处理_v2.md`；本文从「整图级产物」往后接。
> **权威层级**：实际代码 > 配置/checkpoint > 真实产物与日志 > 本文。
> 本文信息密度对齐用户原始训练计划评论，并据 grill 逐条收敛。

## §0 总览：3D 两阶段检测器范式

```text
Find          = RPN          ：80³ 视野上提议 ligand blob（偏 recall）
recrop 48³    = ROI-Align    ：以 blob 的 ligand-area mask 质心，在 80³ 内重裁固定小窗
Match         = 指派/分类头   ：居中 blob ↔ 候选 ligand（含「no-match=背景」拒绝）
Build         = pose 生成头   ：在选定 (blob, ligand) 上做扩散/流匹配生成 pose
```

**总原则：训练分布 = 推理分布。** Match/Build 推理时见到的是「Find 提议 → 以预测 ligand-area mask 质心 recrop 的 48³ 人工 BOX」，所以训练就用同构对象（含人为假阳/假阴），消除暴露偏差。

> 本地 `src/inference/two_stage_basic.py` 是 **Find 的阈值标定 harness**（验证→测试），**不是**本管线；Match/Build 推理尚未实现。可复用的本地件只有 blob 提取 `voxel_postprocess`（threshold→连通域→去小块→合并）。

## §2 BOX 家族与定义

| BOX 类型 | 尺寸 | 来源 | 用途 |
|---|---|---|---|
| **stride-BOX** | 80³ | instance 长方形包络（六面各外扩 **y，默认 20Å**），内部 stride 滑窗，不过滤 | Find 训练正样本主体 |
| **配体中心 BOX**（_C 式） | 80³ | 以 occurrence 的 ligand-area mask 质心居中 | Find 训练（每 instance 有居中视野） |
| **random-BOX** | 80³ | 随机窗口，**受体密度过滤**（≥ 平均密度 ×1.5，均值预统计） | Find 训练可选负/背景（比例可 0%）；**且**后续假阳来源 |
| **bias-BOX** | 80³ | instance ±5–10Å 偏移，**每 instance 默认 3 个**（可配 1..k） | Find 训练完成后，制造人工 BOX 的输入 |
| **人工 BOX（recrop）** | **48³** | 对 bias/random 跑 Find 推理 → 解析中心 blob → 以其 ligand-area mask 质心 recrop | **Match / Build 的输入单元** |

**stride 调参（实操）**：stride 默认档位 **25/30/40/50**；实跑约 100 张图估总量，把全体 stride-BOX 数卡在 **10万~20万**。
**recrop 边界**：48³ 从 80³ 裁余量 16Å，bias 5–10Å + Find 误差通常够；质心越界（> 16Å）的 box **标记并跳过**。

## §3 recrop 中心口径（D12′）

**统一用 ligand-area mask 体素质心**，train/infer 闭合：
- **推理**：Find 预测 ligand-area 概率 → 连通域 → 每 blob mask → 质心 = recrop 中心。
- **训练**：GT ligand-area mask 质心 + 在其上扰动（即 bias-BOX 让 blob 不总居中，模拟 Find 真实误差）。
- 不用配体原子质心：推理期无配体原子、只有预测 mask；两端必须都用 mask 质心，否则 train/infer skew。

## §4 Find：训练 + 后处理落盘

### 4.1 训练
- 输入 BOX：stride-BOX + 配体中心 BOX + 可选 random-BOX（受体密度过滤）。
- 监督：体素 ligand-area（并集 mask）、受体结合原子（4Å）等（数据侧 Stage D/E）。
- 取向：**偏 recall**（D34）。
- 模型：体素分支 + 点云分支 + Sparse Refinement（伪原子由体素粗预测初始化）。

### 4.2 后处理（Find 自己做，D28）
- 对每个 80³ box：threshold → 连通域 → 去小块（`min_component_voxels=32`，对齐 Emap2lig；最终由验证/测试全图推理挑阈值）→ 合并。
- **解析「中心 blob」**：ligand-area mask 质心最接近 box 中心的连通域。

### 4.3 落盘 48³ 人工 BOX 特征包（可扩展 schema）
对 bias + random 跑推理 + 后处理，逐 box dump：
```text
box_key            # {pdb_id}_{bias|random}_{idx}
center_world       # 中心 blob ligand-area mask 质心（世界坐标）
origin/voxel_size  # 48³ 坐标系
density_grid       # (1,48,48,48) float32  ← Build 必需（Emap2lig 式吃原始密度）
ligand_area_prob   # Find 预测 ligand-area 概率（48³）
receptor_tokens    # 窗内受体原子特征 + 结合概率   ← 可能两套（sparse-refine 前/后等）
pseudo_atoms       # Find 伪原子 token（点云分支）  ← 可能两套；每伪原子自带 ligand-area 概率
is_false_positive  # random 来源 / 中心 blob 不对应真实 occurrence
gt_candidate_id    # 中心 blob 命中的 occurrence（假阳 -1）
```
> 受体/伪原子 token「两套」与伪原子概率字段，最终由 Find 最优配置敲定，此处预留。

## §5 Match：输入 / 打分 / 指派 / 假阳假阴 / batch

### 5.1 输入与动机
- 推理自然形态：**x 个把 blob 居中的 48³ BOX + y 个配体对象（且用户提供每种身份的数量）**。
- 训练同构：blob 居中 + 人为假阳/假阴。密度信息必须用。

### 5.2 打分与指派（D33）
- **打分**：`cross-attn(BOX 口袋 token, 配体 token)` → 每 (BOX, 对象) 一个 logit → 分数矩阵。
- **默认**：逐 BOX 在 {配体对象 ∪ no-match} 上 softmax + CE（多个 BOX 可指向同一对象，非一一对应）。
- **计数感知备选（Hungarian）**：用户给了每身份数量 → 把对象按 count 展开成 slot → 在 blobs × slots 上 bipartite（外加 no-match/dummy 收假阳）。
  - **单遍（DETR 式，默认，装得下就用）**：一次带 grad 前向算全 `B×L` logits → 在 **detach** 代价矩阵上 `linear_sum_assignment`（CPU，O(n³)，n 小可忽略）→ 全矩阵算 loss。
  - **两遍（`B×L` 带 grad 装不下时）**：pass1 `no_grad` 全前向算分→解指派；pass2 只对匹配对回传。时间≈2 前向，显存峰值≈no_grad 全前向。
  - 计数也可在推理期当容量约束/先验（softmax 头 + 贪心指派）。

### 5.3 假阳 / 假阴 / 配额（D15′）
- 假阳 = random-BOX 的 blob 人工 BOX（无真实配体）→ 目标 no-match。
- 假阴 = 真 BOX 不提供其配体 → 目标 no-match。
- 配额（真匹配 : no-match）**经验定**：先训完 Find、推理评估、按观察 FP 率/recall 设。

### 5.4 batch 组织（D16′）
- **默认 chunk-BOX × all-ligand**：配体对象少（y 个，count 展开也几十），blob 多 → **整副配体进每个 micro-batch，切 blob**；逐 BOX 分类损失逐 blob 独立 → **对 blob-chunk 梯度累积是精确 trivial 的**。
- **动态/变长 batch + 按 #blob 分桶**提吞吐；超大样本靠梯度累积兜住。
- **退化 chunk-BOX × chunk-ligand**：当配体侧要花算力解析、或不想丢配体多的长尾样本时；代价是逐 BOX softmax 需**跨 ligand-chunk 累积 logits 再 softmax+CE**。
- 同样本默认；后续可用 mask 损失放宽跨样本（跨样本对作 block-diagonal 负样本，但难负样本是「同样本配错」与「Find 假阳」，别被 trivial 跨样本淹没）。

## §6 Build：独立训练 / GT 配准对 / 骨架

### 6.1 训练独立（D29）
- Build 仿 Emap2lig，训练数据 = **(真实 blob 的人工 BOX, 它的真实 ligand, GT pose)**，**假设配对已正确**，只学「密度(+受体)+正确配体 → 生成 pose」。**不依赖 Match 输出**。
- 推理时与 Match 串联（Match 定配对 → Build 建模）。

### 6.2 两个模型（D30）
- **受体+密度** 与 **密度-only** **分开训练两个模型**（不走 dropout 单模型）。
- 数据无差别：48³ dump 是超集（原始密度两者都吃；受体/伪原子存着，受体模型用），两模型各取子集。

### 6.3 模块与骨架（D31/D32）
- **Emap2lig 风格 instance-module 必须、单独**。
- 主干优先级：**Emap2lig**（已有密度条件化，只加受体/伪原子，delta 最小）；借 **PocketXMol** 的受体+配体统一全原子表示思想（不当主干，无密度且其强在数据规模）；AF3/Boltz 经 Emap2lig 已传递；对其他框架开放。
- 输入：48³ 原始密度（必需）+ `ref_pos`（LigandObject 几何先验）+ 受体/伪原子条件（受体模型）；**目标 = GT pose**（per-occurrence 真实坐标，表达到 recrop 帧）。

## §7 训练 / 推理对齐与依赖

```text
[数据侧产物] 整图 exp/sim/diff 密度 + 受体 token + LigandObject + GT 坐标 + ligand-area mask/质心
      │
Find 训练(80³: stride/中心/random) ──训练完──▶ 对 bias+random 推理+后处理 ──▶ 48³ 人工 BOX 包(含 gt_candidate_id/is_FP)
      │                                                                          │
      ▼                                                                          ▼
Match 训练(48³ 包 × 配体对象, 假阳/假阴, 配额)                        Build 训练(48³ 包 × 其 GT 配对 ligand, GT pose)   ← 两者独立
      └──────────────────────────── 推理串联 ───────────────────────────────────┘
   推理: 整图 Find→提取全 blob→各 recrop 48³→Match 定配对→Build 生成 pose
```

- **暴露偏差**：Find 落盘**同时含 GT BOX 与预测 BOX**；Match/Build 用「Find 预测 + 后处理」的人工 BOX 训练。
- **Find recall = 整链硬天花板**（D34）。

## §8 待定与待思考（模型侧）

1. **假阳/假阴配额**：先训完 Find、推理评估后定。
2. **伪原子数量**（旧 1024）是否偏少；是否额外构造/改造点云分支。
3. **BOX 边长**：48³ 默认；若覆盖不下最大整体 ligand（大糖链）再议（撞数据 D1）。
4. **中心消歧信号**：recrop 内有干扰 blob 时，是否加显式中心通道/prompt（Emap2lig `prompt_points` 风格）。
5. **stride 档位**最终值（25/30/40/50 中按总量 10万~20万 实跑定）。
6. **Find 后处理阈值**（threshold/min_component_voxels=32 起步）由验证/测试全图推理挑选。
7. **Hungarian 单遍 vs 两遍**：先单遍，装不下再两遍（已记录为潜在考虑）。
8. **Build 骨架最终选型**（Emap2lig+受体 主线，PocketXMol 思想借鉴，开放其他）。
9. **受体/伪原子 token「两套」与伪原子概率**字段定型（随 Find 最优配置）。
