# pdb-centric-v2：unet_c1 Stage1 方法消融结果

本文同时汇报正式模型的 F1-F1 与 F2-F1 basic 两条流水线。第一个 F1/F2 表示 calibration 上以 PDB 等权 macro semantic F1/F2 最大化语义概率阈值；第二个 F1 表示以 `objective_beta=1` 最大化 macro semantic F1、coverage F1@0.3 与 one-to-one F1@0.3 之和。三模型原始比较仍统一采用 F1-F1；F2-F1 是本模型内部新增的方法消融。

## 共同结果口径

- `test_0` 含 179 个 PDB。`test_1` 含 149 个 PDB，是按 `test_0` 原顺序筛出的严格子集；它不是独立推理，也不是与 `test_0` 独立的统计样本。
- P、R、F1 与 PRAUC 均同时报告 micro 和 PDB 等权 macro；macro F1 是逐 PDB F1 的算术平均，不要求等于 macro P/R 的调和平均。
- 语义 F1 使用最终入选 blobs 的体素并集；语义 PRAUC 使用完整 probability map。两条方法复用同一 probability，因此语义 PRAUC 相同是预期结果。
- coverage 允许多对多命中；one-to-one 使用最大一对一匹配。实例 PRAUC 只应用冻结的两个来源体素门槛，不应用最终 score threshold。
- top-K 成功率没有 micro/macro 之分；表中同时给出成功数、合格 PDB 分母与比例。

- `test_1` 与 `test_0` 重叠，二者差异只描述边界样本移除后的变化，不能当作两次独立重复实验。
- 分辨率、CC 与 occurrence 数可能彼此混杂；分层与 Spearman 数值不构成机制或因果结论。
