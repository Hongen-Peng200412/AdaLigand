# pdb-centric-v2：unet_c1 Stage1 方法消融说明

本文说明正式模型 F1-F1 与新增 F2-F1 basic 两条流水线的条件、产物组织和可追溯边界。三模型原始比较继续统一采用 F1-F1；本轮只在 pdb-centric-v2 模型内部增加并列的 F2-F1 方法消融。

## 名称定义

- F1-F1：第一个 F1 表示 calibration 上以 PDB 等权 macro semantic F1 最大化语义概率阈值；第二个 F1 表示以 `objective_beta=1` 最大化 macro semantic F1、coverage F1@0.3 与 one-to-one F1@0.3 之和。
- F2-F1：第一个 F2 表示 calibration 上以 PDB 等权 macro semantic F2 最大化语义概率阈值；第二个 F1 与上项定义相同。
- 两条方法都使用 basic 分数，即 `source_probability_mean`；F2-F1 不读取 centered、`voxel_final` 或原子字段。

## 模型与训练来源

训练模型、checkpoint 与采样方式没有改变：每个 PDB 每个 epoch 最多生成 50 个 bias BOX，单个 occurrence 至多贡献 1 个；同时固定生成 16 个 context BOX。训练 Job 为 `358384`，正式 checkpoint 为 `/home/penghongen/Feedback/Pocket_Plus/logs/AdaLigand_Stage1_pdb_centric_2-unet_c1-mainchain/unet_c1_mainchain_pdb_centric_2____unet_c1_job358384_20260828T093205_a1_formal/checkpoints/TOP_epoch_03_score_0.5957.ckpt`，SHA-256 为 `8e8bd068ebbebeb8b49db3ddd40c6c485bad322e75f3308b39298b8cea7bec3a`。

## 指标与复用边界

- 语义 F1 使用最终入选 blobs 体素并集；语义 PRAUC 使用完整 probability map。
- coverage 是多对多命中口径；one-to-one 使用最大一对一匹配。
- micro 先合并计数，macro 是逐 PDB 指标算术平均；零分母按正式契约记为 0。
- 两条方法共享模型与 probability，但语义阈值、blobs 和 basic 参数分别冻结；不能把一条方法的 blobs 或参数替换到另一条方法。
- 更换 checkpoint、calibration 清单、阈值网格、候选体素门槛、评分定义或匹配公式时，必须建立新的结果身份。
- 本文与同目录 `结果.md` 只保存在本地工作区，保持 unstaged；未经用户授权不上传服务器。

## 字段定义

- `semantic_micro_precision/recall`：先合并所有 PDB 的 TP、FP、FN 后计算。
- `semantic_macro_precision/recall`：逐 PDB precision/recall 的算术平均。
- `coverage_*`：多对多命中口径；`one_to_one_*`：最大一对一匹配口径。
- 阈值后缀 `0p3/0p5/0p6` 对应双向覆盖阈值 0.3/0.5/0.6。
- `*_micro_prauc_*` 先合并候选级计数；`*_macro_prauc_*` 是逐 PDB PRAUC 算术平均。
- `topk_eligible_pdb_count` 是成功率分母；`top*_success_count_*` 与 `top*_success_ratio_*` 分别是成功数和比例。
