# pdb-centric-v1：unet_c1 Stage1 测试结果

本文汇报冻结 F1 blobs+basic 参数后，在 `test_0` 与派生 `test_1` 上的正式结果。所有性能指标显示六位小数；服务器 JSON 保留完整精度。

## 结果口径

- `test_1`(179个) 和 `test_0`(149个) 可视为独立测试集, 但事实上 `test_1` 等于 `test_0` 经 `1 < ligand occurrence 数 < 100` 过滤后得到的子集, 我们对 `test_1` 复用了 `test_0` 的推理产物。
- P 表示 precision（精确率），R 表示 recall（召回率），PRAUC 是 precision-recall 曲线下面积。micro F1 由合并计数后的 micro P/R 计算；macro F1 是逐 PDB F1 的算术平均，通常不等于表中 macro P/R 的调和平均。
- 语义 F1 使用最终入选 blobs 的体素并集；语义 PRAUC 使用完整 probability map。
- coverage 允许一个预测与多个真实 occurrence 建立命中关系；one-to-one 使用最大一对一匹配。
- 实例 PRAUC 仅应用冻结的 `prefiltered_min_voxel` 与 `min_voxels` 资格门槛，不应用最终 `score_threshold`。
- micro 先合并计数再计算指标；macro 是逐 PDB 指标的算术平均。零分母按正式契约记为 `0.0`。
- top-K 按候选分数降序检查最终入选候选中的前 K 个；只要其中一个候选与任一真实 occurrence 的双向覆盖均达到当前阈值，该 PDB 就记为成功。top-K 不使用 one-to-one 匹配，分母是至少含一个真实 occurrence 的 PDB 数，成功率没有 micro/macro 之分。

## 直接观察

- `test_1` 是 `test_0` 的重叠子集，因此两者差异只能描述边界样本移除后的变化，不能当作两次独立重复实验。
- micro 与 macro 的差距反映大体素图或多 occurrence PDB 对合并计数的影响；两种汇总方式应并列阅读。
- 分辨率、CC 与 occurrence 数的相关系数可能彼此混杂；本文件不据此推断机制。
