# Emap2lig v0.3.4 官方 Find Stage1 补充结果

本文收录不纳入主表的 `test_0` 0.6 档实例指标和全部 top-K 成功率，以及 149-PDB 派生 `test_1` 的完整结果。性能指标保留六位小数；成功率同时报告成功数、分母和百分比。

## 补充口径

- `test_0` 是 179 个 PDB 的正式独立 Find 与评估；其语义和 0.3/0.5 档实例主表见 [主要结果](./%E4%B8%BB%E8%A6%81%E7%BB%93%E6%9E%9C.md)。
- `test_1` 是 `test_0` 中满足 `1 < ligand occurrence 数 < 100` 的 149-PDB 保序子集。它从父 `test_0` 的逐 PDB evaluation NPZ 重新聚合，没有重复执行官方 Find、概率映射、实例映射或逐 PDB 评估，也不是与 `test_0` 独立的统计样本。
- top-K 按实例内 ligand probability 均值降序检查前 K 个候选；同分时保持官方 `blob_N` 顺序。任一候选与任一真实 occurrence 的双向覆盖达到当前阈值，该 PDB 即记为成功。top-K 没有 micro/macro 之分。

## 直接观察

- `test_1` 的语义 micro recall 与 `test_0` 接近，而 micro precision 更低；macro precision、recall、F1 和 PRAUC则略高。两种汇总口径对移除 30 个边界样本的反应不同。
- `test_1` 的三档 top-K 成功率均略高于 `test_0`。该差异只描述保序子集，不构成独立复现或显著性结论。
- 0.5 和 0.6 档的 coverage 与 one-to-one 指标完全相同；0.3 档只有 recall、F1 与 PRAUC存在轻微差异。
