# Emap2lig v0.3.4 官方 Find Stage1 主要结果

本文汇报 Emap2lig v0.3.4 官方 Find 在 179-PDB `test_0` 上的主要结果。该流水线使用官方 Li 自适应阈值，不在 calibration 集上选择参数；表中性能指标保留六位小数，服务器 JSON 保留完整精度。`test_0` 的 0.6 档实例指标、全部 top-K 成功率和 149-PDB 派生 `test_1` 结果见 [补充结果](./%E8%A1%A5%E5%85%85%E7%BB%93%E6%9E%9C.md)。

## 结果摘要

- 语义 micro P、R、F1 和 PRAUC 分别为 `0.011468`、`0.524457`、`0.022444` 和 `0.265008`；macro P、R、F1 和 PRAUC 分别为 `0.037185`、`0.344013`、`0.049855` 和 `0.190718`。
- Emap2lig 在 179 个 PDB 中共保留 63,342 个不少于 32 体素的官方 Li 连通域；117 个 PDB 的实例数超过 100，最大样本 `11jb` 保留 5,100 个实例。全部候选参与语义并集和实例评估，因此 recall 明显高于 precision。
- 在双向覆盖阈值 0.3 下，coverage micro/macro F1 为 `0.022057/0.044072`，one-to-one micro/macro F1 为 `0.022052/0.043937`。两种实例口径接近，但不完全相同。
- top-3、top-4、top-5@0.3 的成功率分别为 `48.60%`、`49.72%` 和 `50.28%`。候选排序前部能覆盖约一半 PDB，但大量低排名候选使全候选 precision 很低。

## 评估口径

- P 表示 precision（精确率），R 表示 recall（召回率），PRAUC 表示 precision-recall 曲线下面积。micro 先合并所有 PDB 的计数再计算；macro 是逐 PDB 指标的算术平均。macro F1 通常不等于表中 macro P 与 macro R 的调和平均；零分母按正式契约记为 `0.0`。
- 官方 Find 对每个输出通道使用 `threshold_li(..., initial_guess=0.1)` 求自适应阈值。本文没有在 calibration 或测试结果上选择额外语义阈值。
- `measure.label(..., connectivity=3)` 定义 26 邻域连通域；官方少于 32 体素的实例过滤保持不变。每个保留实例均设为 `selected=True`、`prauc_eligible=True`，分数是该实例在 Emap2lig 原生 ligand probability 中的均值。
- 语义 F1 使用全部官方保留实例映射后的体素并集；语义 PRAUC 使用完整 ligand probability。实例 PRAUC 使用全部官方保留实例，不增加分数阈值或体素门槛。
- coverage 允许一个预测与多个真实 ligand occurrence 建立命中关系；one-to-one 使用最大一对一匹配。

## 直接观察

- 语义和实例指标都表现为 recall 高于 precision。该结果与“所有不少于 32 体素的官方实例均入选”的冻结契约一致；本文不把这种描述性关系解释为单一因果结论。
- macro F1 高于 micro F1，说明按 PDB 等权后，少数含大量预测体素或大量候选的样本不再以体量直接主导汇总。
- coverage 与 one-to-one 在 0.5 档完全相同，在 0.3 档只有轻微差异；这表示达到较高双向覆盖的命中在本测试中很少产生额外的多对多匹配收益。
