# Find_1（pdb-centric-v2，CryoAtom2 预测受体）Stage1 主要结果

本文汇报 `Find_1` 在 149-PDB `test_1` 上的主要结果，并列展示 F1 blobs+basic 与 F2 blobs+Gaussian 两条流水线。性能指标保留六位小数；服务器 JSON 保留完整精度。`test_1` 是 179-PDB `test_0` 的保序子集，不是独立推理或独立统计样本。top-K 成功率和父 `test_0` 的结果见 [补充结果](./%E8%A1%A5%E5%85%85%E7%BB%93%E6%9E%9C.md)。

## 结果摘要

- basic 的语义 micro/macro F1 分别为 `0.540695/0.490388`，Gaussian 分别为 `0.526640/0.480093`。
- 两条流水线共用完整图 probability map，因此语义 PRAUC 完全相同；语义 F1 使用各自语义阈值和最终入选候选的体素并集，数值可以不同。
- Gaussian 在各实例阈值上均提高 precision、降低 recall。它在 0.5 档的 macro F1 和 0.6 档的 micro F1 略高于 basic，其余主要实例 F1 由 basic 更高。
- Gaussian 的 macro 实例 PRAUC 在 0.3 和 0.5 档高于 basic，但 micro 实例 PRAUC 在三档均低于 basic；两种汇总方式不能相互替代。

## 评估口径

- basic 流水线在 calibration 上最大化 PDB 等权 macro semantic F1，候选分数为 `source_probability_mean`。
- Gaussian 流水线在 calibration 上最大化 PDB 等权 macro semantic F2，随后对 F2 blobs 完成 centered 前向，并用 Find A 原子 Gaussian 正负项重新打分。
- 两条流水线的候选参数均在 calibration 上以 `objective_beta=1` 最大化 macro semantic F1、coverage F1@0.3 与 one-to-one F1@0.3 之和。
- P 表示 precision（精确率），R 表示 recall（召回率），PRAUC 表示 precision-recall 曲线下面积。micro 先合并全部 PDB 的计数再计算；macro 是逐 PDB 指标的算术平均。macro F1 通常不等于表中 macro P 与 macro R 的调和平均。零分母按正式契约记为 `0.0`。
- 语义 F1 使用最终入选候选的体素并集；语义 PRAUC 使用完整 probability map。实例 PRAUC 只应用冻结的 `prefiltered_min_voxel` 与 `min_voxels` 资格门槛，不应用最终 `score_threshold`。
- coverage 允许一个预测与多个真实 ligand occurrence 建立命中关系；one-to-one 使用最大一对一匹配。

## 直接观察

- basic 在 `test_1` 的语义 F1 和大多数实例 F1 上更高；Gaussian 并未在 CryoAtom2 受体条件下形成一致的 F1 优势。
- Gaussian 的 precision 上升与 recall 下降同时发生，说明其冻结分数阈值选择了更少但更集中的候选。该结果是描述性观察，不等同于因果或显著性结论。
- 两条流水线同时使用不同语义阈值、候选集和候选打分，因此这里比较的是完整流水线，不是只替换打分函数的单因素消融。
